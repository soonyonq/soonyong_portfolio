# 안순용 | 총무 · 경영지원 포트폴리오

## 구성

- `index.html` — 단일 페이지 포트폴리오
- `style.css` — 블루·그레이 기반 디자인 (외부 UI 라이브러리를 사용한 것은 아님)
- `script.js` — 스크롤 등장, 카운터, 프로필 키워드 인터랙션, 사례 단계, 경력 아코디언, 프로젝트 상세 팝업
- `projects-data.js` — 8개 업무 사례 데이터
- `assets/` — 제공된 사진 및 이력서 PDF

## 실행 / GitHub Pages

압축 파일을 풀고 모든 파일을 저장소 루트에 업로드합니다. `Settings → Pages → Deploy from a branch → main / (root)`를 선택합니다. 외부 빌드 단계가 필요하지 않습니다.

## 원본 참고와 구현 범위

화면 흐름, 섹션 구분, 원형 프로필과 키워드 인터랙션, 수치 카드, 문제·실행·결과 구조, 스크롤 등장 효과를 참고해 새롭게 작성했습니다. 원본 HTML·CSS·JS 코드를 복사하지 않았습니다.

색상은 공개된 토스 디자인 시스템의 `#3182F6`, `#191F28`, `#F2F4F6` 등과 브랜드 블루 `#0064FF`를 사용합니다. 토스의 로고, 전용 폰트 파일, UI 라이브러리는 포함하지 않습니다.

사진은 사용자가 제공한 개인 포트폴리오 사진만 포함했습니다. 프로젝트별 사진이 없는 사례에는 무관한 이미지를 삽입하지 않았습니다.

## 공개 전 검수

이력서 PDF에 연락처가 포함되어 있습니다. GitHub Pages 배포 시 이력서와 이메일이 공개됩니다.


## 1차 시인성 개선 (V2)
- 회사 로고를 읽기 쉬운 크기로 통일하고, 경력 아코디언에도 배치
- 첫 화면 정보 카드 8개: 관리 범위 4개 / 대표 성과 4개
- 업로드한 경력기술서와 최신 이력서 내용을 기준으로 카드와 경력별 핵심 업무 갱신
- 사용도구에서 From-To 삭제
- 한국어 단어 단위 줄바꿈, 연락 섹션의 문단 폭과 길이 조정
- 로고는 사용자가 제공한 원본 이미지를 적용했으며, 상단 및 경력 영역에는 회사명이 포함된 전체 로고를 표시합니다.

## V5 - 경력기술서 기반 상세 보강 및 사용자 제공 로고
- 8개 프로젝트 상세 설명을 최신 경력기술서의 문제, 계획, 실행, 정량 성과로 재구성했습니다.
- 안전관리비 구매처/사진대지/현장 검증, 자산 334건 실사, 유리 하자 공동재현, 집무실 시방서와 자재 사전 확보 사례 등 추가했습니다.
- `assets/logo-*.png`는 사용자 제공 로고 이미지에서 심볼 부분만 크롭한 비트맵 PNG입니다. 원본 이미지는 `assets/original-logo-*.png`에 있습니다.

- 원상복구비 약 3~4억 원은 추정 회피비용이며 확정 현금 절감액이 아닙니다.
